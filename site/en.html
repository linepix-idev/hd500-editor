HD500 Editor

A free, open editor for the Line 6 POD HD500, now that the official software is no longer maintained. Runs on Linux, Windows and macOS and talks to the pedal directly over USB.

Download

Releases live on the project’s releases page.

Current version: 0.2.14 (beta)

See releases

What it does

  • Signal graph: drag effects before/after the amp and between paths A and B.
  • Live editing of every amp, cab and effect, mixer, footswitches and expression pedals.
  • 8 sets × 64 presets: rename, copy, swap, export and import (.h5e), with an automatic backup before every write.
  • Nothing is written to the pedal’s memory until you press “Save to pedal”.

Systems and limitations

Linux

Editor and USB audio work together. .deb package or AppImage.

PDF guide — Linux

Windows

The pedal is either a sound card (Line 6’s official driver) or editable in the app (WinUSB), never both at once. Unsigned installer: SmartScreen warns.

PDF guide — Windows

macOS

The editor works. Installer not signed by Apple (right-click ▸ Open). Audio input and the pedal under System Settings ▸ Sound need an Apple certificate and do not work yet.

PDF guide — macOS
